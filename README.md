# SECURE

Este Proyecto propone el diseño e implementación de un Sistema multiagente basado en el protocolo de contexto de modelos (MCP) y habilidades (Skills/Tools) especializados para la automatización, detección y validación ética de vulnerabilidades en aplicaciones y servicios web. Las soluciones tradicionales operan predominantemente en consola(CLI) y generan reportes planos difíciles de interpretar. Es por esto que se propone, una interfaz gráfica dedicada y enfocada en la legibilidad mediante reportes estructurados y ayudas visuales que facilitan la comprensión del impacto del riesgo, por otro lado, ofrecer trazabilidad agentica que registra y expone cómo los agentes autónomos razonen, coordinan estrategia y ejecutan paso a paso los ataques en un entorno controlado.
